

# Download and Run

## 1. Repository Clone Karein

```bash
git clone https://github.com/self72/one-stop-solution.git
```

## 2. Project Folder Me Jaayein

```bash
cd one-stop-solution
```

## 3. Dependencies Install Karein

```bash
npm install
```

## 4. Environment Variables Configure Karein

Root folder me `.env` file banayein:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

## 5. Development Server Start Karein

```bash
npm run dev
```

Application browser me open hogi:

```text
http://localhost:5173
```

## 6. Production Build

```bash
npm run build
```

## 7. Production Preview

```bash
npm run preview
```

---

### Requirements

* Node.js (v18+)
* npm
* Git
* VS Code (Recommended)

### VS Code Me Run Karne Ke Liye

1. Repository clone karein.
2. VS Code me project folder open karein.
3. **Terminal → New Terminal** open karein.
4. Commands run karein:

```bash
npm install
npm run dev
```
